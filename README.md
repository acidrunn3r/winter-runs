# WINTER RUNS

Каталог зимних трасс и событий Московской и Тверской областей. Разделы TRACKS и EVENTS.

Данные о сезоне, допуске автомобиля, датах и регистрации нужно проверять у организатора.

Дорожные расстояния от двух обезличенных баз: [DISTANCES.md](DISTANCES.md). Местоположение баз, профиль владельца и описание автомобиля не публикуются.

GitHub Pages: ветка main, корень репозитория.
